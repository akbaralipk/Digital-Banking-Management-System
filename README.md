# Digital Banking Management System (DBMS)

## Overview

The Digital Banking Management System (DBMS) is a secure and interactive application built using Python and Streamlit.  
It allows users to create multiple bank accounts, perform deposits, withdrawals, and balance inquiries — all protected by PIN-based authentication.

## Features

- Create new accounts with unique account numbers and PINs  
- Deposit and withdraw money securely  
- Check account balance anytime  
- View complete transaction history  
- Session-based storage to manage multiple accounts

## Technologies Used

| Technology               | Purpose                              |
|--------------------------|---------------------------------------|
| Python                   | Core programming                      |
| Streamlit                | Web interface                         |
| OOP (Abstract Classes)   | Modular and scalable system design    |
